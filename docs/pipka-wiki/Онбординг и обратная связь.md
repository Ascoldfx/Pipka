# Онбординг и обратная связь

Приветственный онбординг для новых пользователей и форма обратной связи с мгновенным уведомлением админа в Telegram. Введены 7 августа 2026 (migration `0012_onboarding_and_feedback`).

Файлы: `app/api/feedback.py`, модель `UserFeedback` (`app/models/user.py`), UI — модалки в `app/static/dashboard.html` + обработчики в `app/static/js/events.js`.

## Онбординг

- Флаг `users.onboarded` (дефолт `false`).
- Пока флаг не выставлен, дашборд показывает welcome-модалку с пошаговой настройкой профиля (target titles, страны, резюме — см. [[Resume parsing]]).
- `POST /api/onboarding/complete` → `onboarded = true`, модалка больше не появляется.
- Для гостей (без логина) вместо онбординга — постоянный гостевой баннер и лендинг с переключателем языка ([[Frontend]]).

## Обратная связь

`POST /api/feedback` (требует сессию + CSRF):

| Поле | Ограничение |
|---|---|
| `category` | `general` (дефолт) / `bug` / `feature` / `question`; иное → `422 Unknown feedback category` |
| `message` | 5–4000 символов, обрезаются пробелы |
| `contact` | опционально, ≤255 символов; если пусто — подставляется email пользователя |

Запись сохраняется в таблицу `user_feedbacks` ([[База данных]]), затем отправляется Telegram-уведомление через Bot API.

**Кому уходит уведомление:** на Telegram ID из `ALLOWED_TELEGRAM_IDS` (а не по `role=admin`). Если список пуст — уведомление не отправляется, отзыв только в БД. Ошибка отправки не ломает сохранение.
