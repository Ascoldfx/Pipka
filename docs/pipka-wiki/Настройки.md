#config

# Настройки

Все настройки — через `.env` файл на сервере (`/opt/pipka/.env`).
Модель: `app/config.py` (pydantic-settings).

## Обязательные

| Переменная | Описание |
|-----------|---------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram бота |
| `ADZUNA_APP_ID` | Adzuna API ID |
| `ADZUNA_APP_KEY` | Adzuna API Key |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL |
| `GOOGLE_CLIENT_ID` | Google OAuth Client ID |
| `GOOGLE_CLIENT_SECRET` | Google OAuth Client Secret |
| `SESSION_SECRET` | Секрет для подписи session cookies |

|-----------|--------|---------|
| `ARBEITSAGENTUR_API_KEY` | `jobboerse-jobsuche` | Bundesagentur für Arbeit (публичный) |

**Как включить обратно** (на сервере `/opt/pipka/.env`):
```env
DISABLED_SOURCES=          # пусто → arbeitsagentur снова активен
JOBSPY_SITES=indeed,linkedin   # LinkedIn снова активен
```
После правки — `docker compose up -d` (не restart — env читается при create).

Gupy активируется только после официального одобрения Pipka как job-board
партнёра. Документация и форма подключения:
https://developers.gupy.io/docs/integra%C3%A7%C3%A3o-com-job-boards-parceiros
Кандидатский портал Gupy намеренно не скрейпится.

### Поиск и embeddings
| Переменная | Дефолт | Описание |
|-----------|--------|---------|
| `EMBEDDING_ENABLED` | `True` | Фоновая индексация вакансий/профилей в pgvector |
| `EMBEDDING_PROVIDER` | `nvidia` | `nvidia` (Nemotron) или `gemini`; определяет API и требуемый ключ. |
| `EMBEDDING_MODEL` | `nvidia/nemotron-3-embed-1b` | Модель semantic search. |
| `EMBEDDING_DIMENSION` | `2048` | Размерность Nemotron-векторов; migration `0010` переводит pgvector-колонки и очищает несовместимый Gemini-индекс. |
| `EMBEDDING_BATCH_DELAY` | `0.8` | Пауза между embedding-вызовами |
| `EMBEDDING_JOBS_PER_RUN` | `70` | Сколько вакансий индексировать за тик |
| `EMBEDDING_PROFILES_PER_RUN` | `20` | Сколько профилей индексировать за тик |
| `EMBEDDING_INDEX_INTERVAL_HOURS` | `2` | Периодичность scheduler job `embed_index` |
| `SEMANTIC_SEARCH_LIMIT` | `500` | Top-N кандидатов для `GET /api/jobs?semantic=1` |
| `NVIDIA_EMBEDDING_TIMEOUT_SECONDS` | `30.0` | Таймаут вызова NVIDIA `/v1/embeddings`. |
| `EMBEDDING_BURST_INTERVAL_MINUTES` | `30` | NVIDIA-only интервал ускоренной обработки большой очереди. |
| `EMBEDDING_BURST_QUEUE_THRESHOLD` | `100` | Burst запускается только когда релевантная очередь строго больше этого числа. |
| `EMBEDDING_INDEX_MAX_AGE_DAYS` | `31` | Не индексировать старый архив вакансий. |
| `EMBEDDING_INDEX_COUNTRY` | `de` | Legacy fallback для прямых helper-вызовов; scheduler и Ops индексируют объединение `preferred_countries` активных users ([[Мульти-юзер очереди]]). |
| `EMBEDDING_INDEX_MIN_SCORE` | `60` | Нужен хотя бы один AI score не ниже порога. |
| `SEMANTIC_SKIP_ENABLED` | `true` | Включает семантическое **понижение приоритета** кандидатов. С 01.08.2026 (migration `0008`) похожесть больше не отсекает вакансии — только сортирует. |
| `SEMANTIC_SKIP_THRESHOLD` | `0.5` | Cosine-порог: кандидаты ниже него уходят в конец очереди AI-скоринга. Работает только со свежим эмбеддингом профиля. |

### NVIDIA Build (fallback + опциональный idle rescorer)
| Переменная | Дефолт | Описание |
|-----------|--------|---------|
| `NVIDIA_API_KEY` | `""` | NVIDIA API credential. Используется для fallback scoring и (при `EMBEDDING_PROVIDER=nvidia`) embeddings. Не хранить значение в wiki. |
| `NVIDIA_IDLE_RESCORE_ENABLED` | `False` | Регистрировать 30-минутный idle rescore для DE. По умолчанию выключен из-за нестабильности NVIDIA под bulk-нагрузкой |
| `NVIDIA_MODEL` | `poolside/laguna-xs-2.1` | Текущий fallback. Проверен на полном scoring prompt и JSON; используется streaming. Другие NVIDIA catalog модели часто возвращали 404/503 или timeout. |
| `NVIDIA_BASE_URL` | `https://integrate.api.nvidia.com/v1` | Endpoint (OpenAI-совместимый) |
| `NVIDIA_BATCH_DELAY` | `2.0` | Задержка между вызовами (сек) |
| `NVIDIA_SCORING_BATCH_SIZE` | `1` | Fallback работает по одной вакансии за API-запрос; последовательная обработка сохраняет свежий порядок. |
| `NVIDIA_SCORING_TIMEOUT_SECONDS` | `60` | Лимит HTTP read; поток держит соединение активным во время генерации. Общий wall-clock guard — 2× этого значения. |
| `NVIDIA_SCORING_MAX_ATTEMPTS` | `1` | Повторы выключены для предотвращения долгого зависания очереди. |
| `NVIDIA_SCORING_MAX_TOKENS` | `768` | Верхняя граница output scoring fallback. |
| `NVIDIA_SCORING_REASONING_EFFORT` | `low` | Передаётся как `reasoning_effort` в NVIDIA-запрос скоринга — держит reasoning-часть короткой, чтобы ответ укладывался в timeout. |
| `NVIDIA_MAX_PER_RUN` | `300` | Cap вакансий за один тик scheduler |
| `NVIDIA_COUNTRY` | `de` | ISO-код страны для фильтра idle rescore |
| `NVIDIA_RESCORE_STALE_DAYS` | `7` | Освежать оценки старше N дней |

`nvidia_idle_rescore_enabled=false` по умолчанию; production основной fallback scoring не зависит от idle rescore.

## Production snapshot: 23.09.2026

- Активны `GEMINI_API_KEY` и `NVIDIA_API_KEY`; фактические модели: `gemini-3.6-flash`, `poolside/laguna-xs-2.1`.

## Настройки профиля пользователя (UI)

Хранятся в [[База данных]]. Управляются через Settings tab на сайте.

| Поле | Описание |
|------|---------|
| Resume text | Текст резюме / ключевые навыки |
| Target titles | Желаемые должности |
| Target Companies Watchlist | Список компаний для мониторинга (Nestlé, Bayer…) — скан каждые 6 ч |
| Excluded keywords | Фразы-исключения в названии и описании вакансии |
| Blocked companies | Компании-исключения; только точное совпадение с `company_name` |
| **English Only** | При включении скрывает уверенно неанглоязычные title/description; короткий или неоднозначный текст передаётся AI |
| Work mode | Any / Remote / Hybrid / On-site |
| Preferred countries | Страны поиска |
| Hidden countries | Страны, скрытые из основной ленты. Сбор и скоринг продолжаются; явный country-фильтр временно показывает скрытую страну |
